Install

Three steps

A Mac with Apple silicon (macOS 14+) and Tailscale on both devices.

  1. Build 
    git clone https://github.com/Fume-Finance/duo-mac.git
cd duo-mac && ./build.sh
  2. Open Duo Mac The setup guide ticks off each step.
  3. Scan, add, allow Scan the QR code, add it to your Home Screen, click Allow.
